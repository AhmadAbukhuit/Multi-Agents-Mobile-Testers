# Code-Aware QA Testing Brief

You have been provided with a **Codebase Test Guide** (`results/CODE_TEST_GUIDE.md`) and a **Persona Playbook** (`results/code_context.json`) generated by the 5 Code-Understanding Agents after reading the app's source project (`package.json`, navigation routes, forms, and state handlers).

Use this knowledge while testing the compiled application on the emulator/simulator:

1. **Follow your persona playbook first:** Prioritize the `focus_screens`, `recommended_actions`, and `watch_outs` generated for your persona.
2. **Verify real controls against code expectations:** Inspect screenshots with `screen.py` after each action and prefer `tap_element` on Set-of-Mark `[id]` tags when available. If a screen, button, or form found in source code is missing, broken, overflows, or fails to transition in the compiled release `.apk`, record it as a bug.
3. **Use realistic & persona-appropriate inputs:** Type the sample or edge-case inputs discovered for the form fields (`type.py` or `adb shell input text`), checking validation messages, dark mode contrast, RTL layout, and text scaling per your persona.
4. **Finish cleanly:** Write `results/<persona>/report.md` and valid `results/<persona>/findings.json` (`score` 1-10 and `issues` list).
